# Security policy

Si crees que encontraste una vulnerabilidad de seguridad, reportala de forma responsable:

1. Preferido: reportar vía **GitHub Security Advisories** (botón “Security” en el repo).
2. Alternativa: abrir un issue y marcarlo con etiqueta `security` (sin compartir secretos).

No es necesario incluir datos sensibles o credenciales: lo importante es la descripción del impacto y los pasos para reproducirlo de forma segura.
